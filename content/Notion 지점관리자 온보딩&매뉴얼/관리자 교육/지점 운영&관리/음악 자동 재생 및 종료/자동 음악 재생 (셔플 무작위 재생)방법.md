> [!note] 💡    음악 자동 재생의 장점은
> - 오픈 스태프가 지각 하였을 때 회원님들이 근무자가 없더라도 노래를 들으면서 운동할 수 있게 하는 시스템입니다.
> - 단점이라고 한다면 1가지 파일로 되어있는 음악이 항상 같은 시간에 흘러 나오기에 같은 시간에 운동을 오시는 분들이라면, 계속 똑같은 음악을 들을 수 밖에 없어 지루함을 느낄 수 있어,
> - 셔플, 무작위 재생 시스템을 도입 하게 되었습니다. 방법은 아래와 같습니다.
>
>
> 시작하기 전 아래 구글 드라이브 링크 에서 파일을 다운 받아주세요 🙂
>
> [https://drive.google.com/drive/folders/1xEgwbII4VtrpIqrSOcUSXgEflOdi87it?usp=drive_link](https://drive.google.com/drive/folders/1xEgwbII4VtrpIqrSOcUSXgEflOdi87it?usp=drive_link)

![a76e0cd3-자동재생_1](<../../../_attachments/a76e0cd3-자동재생_1.png>)

1. 링크 들어가서 음원 클릭 후 다운로드

![2a884d20-2](<../../../_attachments/2a884d20-2.png>)

1. 다운로드 받은 파일의 압축을 풀어 주세요 

![c907345f-3](<../../../_attachments/c907345f-3.png>)

1. Ctrl + A → 마우스 우클릭
2. 압축 푼 폴더 열기
3. Window media player 목록에 추가 클릭

![de8763aa-4](<../../../_attachments/de8763aa-4.png>)

1. 라이브러리로 전환 클릭

![cc509ab5-5](<../../../_attachments/cc509ab5-5.png>)

1. 좌측 재생 목록 클릭
2. 우측 “여기를 클릭” 클릭 

![386f03df-6](<../../../_attachments/386f03df-6.png>)

1. 재생 목록 이름 변경 
    openmusic
2. 재생 목록 더블 클릭

![f1b1b16f-7](<../../../_attachments/f1b1b16f-7.png>)

1. 우측 상단 “재생” 클릭
2. 음악 한개 클릭 후 Ctrl + A
3. 마우스로 드래그 하여 좌측으로 이동

![a2030a92-8](<../../../_attachments/a2030a92-8.png>)

1. 우 클릭 후 파일 위치 열기

![14c2b9b8-10](<../../../_attachments/14c2b9b8-10.png>)

1. Wpl 파일 생성 확인
2. 우클릭 → “속성” 클릭

![bcf925bc-11](<../../../_attachments/bcf925bc-11.png>)

1. 위치 : C:\Users\PCR\Music\재생 목록 복사

![f92cbddc-11-1](<../../../_attachments/f92cbddc-11-1.png>)

1. 작업스케줄러 실행
2. openmusic 또는 오픈뮤직 작업 클릭 후 우측 하단 속성 클릭

![9cbf6195-셔플](<../../../_attachments/9cbf6195-셔플.png>)

1. 실행 후 꼭 셔플 버튼 클릭 !! 해주세요 !!!
