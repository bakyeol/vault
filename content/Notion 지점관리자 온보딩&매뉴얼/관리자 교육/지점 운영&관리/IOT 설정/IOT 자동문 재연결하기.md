#### 1. IOT 기기 연결, Wifi 연결 확인

먼저 iot 기기가 자동문과 잘 연결되어 있는지 확인해주세요!

아래 문서를 참고해서 기기 연결과 wifi 연결 모두 확인해주세요!

[IOT 페어링 방법](<IOT 페어링 방법.md>) 

#### 2. 짐박스 PASS 어플 캐시 및 데이터 삭제

**짐박스 어플을 길게 꾹- 누르기 > 애플리케이션 정보 > 저장공간 > 데이터 삭제, 캐시 삭제**

#### 3. 올바른 로그인 정보 입력

대부분 잘못된 지점번호와 디바이스번호로 인해 자동 출입문이 작동하지 않아요

올바른 로그인 정보로 입력해주세요!

|   | **지점번호** | **디바이스번호** |
| --- | --- | --- |
| **신대방 - 웨이트존** | 000008 | pin_machine |
| **신대방 - 유산소존** | 000008 | pin_cardio |
| **성신여대** | 000021 | pin_B2F |

#### 4. 짐박스 PASS 어플 재설치

데이터, 캐시 삭제로도 해결 되지 않는다면 짐박스 PASS 어플만 삭제해주세요!

이후 구글 스토어에서 다시 재설치 해주세요

재설치 후 위의 로그인 정보로 다시 로그인 해주세요

**PASS 어플만** **삭제 후 구글 스토어 진입 >  오른쪽 상단 계정(동그라미 아이콘) > 앱 및 기기관리 > 관리 > 설치되지 않음 > 짐박스 PASS 어플 선택 > 설치**
