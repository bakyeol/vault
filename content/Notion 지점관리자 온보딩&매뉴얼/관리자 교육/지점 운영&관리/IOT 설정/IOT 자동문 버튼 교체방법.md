## IOT 버튼 교체 방법(자동문)

[설치 방법]

- 준비물 :사다리or 발판 , 십자드라이버, [ 신규 IOT 기기, 새로운 버튼 ] 지점 별로 배송 될 예정

1. 자동문 양옆 나사 제거 후 상판 고정
2. 기존 IOT 주파수 확인 후 새로운 IOT기기 주파수 다르게 설정 , 새로운 IOT에 설정 된 주파수와 같게 새로운 버튼 주파수 설정
3. 기존 버튼 제거 후, 새로운 버튼 장착
4. 새로운 IOT 기기를 연결 부위와 최대한 가깝게 부착해야 간섭을 안 받음.
5. 새로운 IOT 기기 (노란색 2가닥 신호, 회색 2가닥 전원, [흰색 2가닥은 사용 안 함]) 옆 연결 부위에 색깔에 맞게 연결
6. 연결 부위 색 누르면 선 빠짐 새로운 선 같이 꼬아서 넣어주면 완료

[기존 버튼은 나중에 버튼 고장 시 주파수 설정해서 재 사용 가능]
