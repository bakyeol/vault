### 스태프 정산

---

**월초 ~ 월말까지의 기간****에 대해 정산을 진행하고 있어요.**

`월 급여 테이블 마감 : ~해당 월 25일 까지`

`26일 ~ 말일 기간에 대한 근무 시간은 예상 근무 시간으로 계산 해주세요. (변동사항은 다음달 급여에 소급적용`)

`26일 이후 입사자는 9월 귀속 급여에 포함 해주세요.`

1️⃣ 말 일까지의 지점 스태프 근무 파악하여, 작성 해주세요 [지점 관리 시트 복사 붙여 넣기 절대 금지 꼭 수기로 작성 해주세요]

2️⃣ 지점 스태프들에게 근무 표 공유 후 맞는 지 확인해 주세요 [본인 확인했다는 증거 남기기]

3️⃣ 지점 관리자와 스태프 확인이 모두 끝났으면, 지점장 시트에 해당 월 근무 표 복사 해 놓고 다시 한번 이상 있는지 검토

4️⃣ 지점장 시트 급여 보고 내용 최신 화

5️⃣ 근로 계약서 및 사직서 모두 싸인 에서 서명 확인

6️⃣ 입/퇴사/계약연장 공유 구글 시트 업데이트 [(시트 링크)](https://docs.google.com/spreadsheets/d/1h_-RY3O9FPJBBkUVbx4EnnKbt0DIz5MC5caRwBdtMxo/edit?gid=1052926981#gid=1052926981)

7️⃣ 스태프의 주민 번호 진위 여부 확인 [주민 번호는 아래 파일에서 직접 써보고 확인 ]

![[257cac6c-주민등록진위 - 복사본.xlsx]]

![e5364ab1-Untitled](<../../첨부파일/e5364ab1-Untitled.png>)

월 ~ 금 실제 근무시간 작성 시 자동으로 주휴 시간 계산

- 주 15시간 이상 근무 시 발생
- 1주간 소정 근로일 개근

→  두 가지 조건이 충족된 경우 발생

→  발생이 안되는 상황이라면 “ 0 “ 기입 

→  주 휴일이 “일요일” 이기 때문에 토요일 퇴사 시 미지급 

예시 ) 

- 미들근무자 : 22일 마감 대근

1) 대근시간 작성 : 실제 근무시간

2) 야간시간 작성 : 22시 ~ 24시 - 2시간

3) 비고 작성 : 마감

4) 주휴 계산 : 한 주 실제 근무시간 [÷](https://dict.wordrow.kr/m/57455/) 월~금 = 주휴시간

- 마감근무자 : 22일 결근

1) 비고 작성 : 결근

2) 주휴수당 미발생

1. 야근수당 : 야근 시 1.5배 지급 (22시 ~ 06시까지)

![d37939a4-Untitled](<../../첨부파일/d37939a4-Untitled.png>)

22시 ~ 06시까지 실제 근무시간 작성

예시)

- 마감근무자 : 18시 ~ 24시 계약서 작성

1) 야간시간 작성 : 22시 ~ 24시 = 총 2시간

- 미들근무자 : 22일 마감 대근

1) 대근시간 작성 : 실제 근무시간 

2) 야간시간 작성 : 22시~24시 = 총 2시간

3) 비고 작성 : 마감

4) 연장근로시간 계산 : 실제 근무시간 * 0.5 = 연장근로수당

**2 * 0.5 = 1**

1. 연장근로수당 : 대근 시 1.5배 지급

대근자 : 실제 대근시간 작성 / 결근자 : 주휴 미발생

예시)

- 미들근무자 : 22일 대근

1) 대근시간 작성 : 실제 근무시간 

2) 비고 작성 : 오픈

3) 연장근로수당 계산 : 실제 대근시간 * 0.5 = 연장근로수당

**6 * 0.5 = 3**

- 오픈근무자 : 22일 결근

2) 주휴 미발생
