1. VOC 확인 

- DIR 시트 
- HQS 확인 [지역관리자]

- [ ] 지점으로 들어오는 컴플레인을 매일 확인 후, 빠른 시일 안에 해결 할 수 있도록 일일 계획에 추가
    

1. 기구 확인 

- 지점 운영 시트 → 기구 수리 시트 
    [지점운영시트 내 기구수리시트 확인 후 지점에서 고칠 수 있는 문제 인지 라운딩 시 확인합니다]
- 지점 운영 시트 → 본사 기구 수리 시트 
    [자체 해결이 되지 않는 기구들은 시트에 올림과 동시에 수리업체와 소통하여 빠르게 수리합니다.]

1. 스태프 교육 확인

- 영수증 리뷰 시트 확인
    [지점 내 영수증 리뷰 일 5개 이하인지 확인 후 낮다면, 리뷰 안내 교육 실시 합니다]
- V2 시트 확인
    [환불이나, 스태프들이 본사로 올리는 내용들을 확인 후 메뉴얼 관련 부족한 스태프 파악 후 교육 실시]
- 지점장 시트 확인 
    [근로계약서 작성이 누락 되는 일 없게 관리 합니다. ]
- 포대 시트 확인
    [포대 사진과 개 수가 맞는지 확인하고, 미비된 경우 재교육 실시합니다.]
- 스태프들이 밝게 인사 하는 지 체크 
    - 입,퇴사자 확인 
        a. 4대보험가입 여부에 따라 취득,상실을 확인, 퇴사자의 경우 계약만료통지서 or 사직서 작성 여부 확인
        b. 채용 공고 지원자 확인 후 면접 일정 잡기 

1. 지점 라운딩 

- 지점 내 디자인팀에서 제작 하지 않은 사인물 확인
- 지점 출입구 복도, 출입문 확인 
- 우산 꽂이 확인
- 지점 트레이너 어드민과 같은지 확인
- 카운터 확인 
    a. 제빙기,커피머신,블렌더,쇼케이스 등 정상 작동 확인 
    b, 청결도 확인 [기기+싱크대+BCAA 통, 선반 상부]
    c. 보이는 부분 재고 및 걸레 
- 스트레칭존 정리 상태, 청결도 체크 
- 소도구 및 그립류 정리 상태
- 지점내 거울 체크
- 지점내 조명 체크 
- 기구 결합 부분 확인 
- 기구 오일링 확인 
- 기구 청결도 확인 [핀 머신 무게추 상단 먼지 , 사이 사이 오일 떡짐 등]
- 유산소 머신 [벨트 쏠림, 머신 아래 먼지,땀자국]
- 프리 웨이트 [슬링렉 결합, 덤벨,덤벨렉,바벨렉 먼지]
- 원판 정리 상태 
- 기구 오와 열 [메타 포트 기준]
- 쓰레기통, 물 비움 통, 정수기 청결도 
- 필드 바닥
- 탈의실, 샤워실 청결 상태
- 공용,개인 락커 상단 및 내부 확인 [고장,분실 포함]

1. 재고 관리

- 지점에서 판매 품목이 품절 되지 않도록 발주 

1. 업체 소통

- 청소업체를 사용하고 있는 지점일 경우 청소 구역 매일 확인 후 만족스럽지 못한 상태라면, 업체와 소통
- 세탁업체를 사용하고 있는 지점일 경우 회원복, 수건 악취 및 수거 배송이 만족스럽지 못한 상태라면, 업체 소통 
- 소통을 했는데도, 개선되지 않을 경우 대체 업체 컨텍 후 지역관리자와 상의
